# NLocale MCP server

Public, read-only remote MCP server for NLocale, a sourced local guide to Aisne, France (events, places, restaurants, stays and local authorities, in six languages). Publisher: SASU JAK MOOH.

- Endpoint: https://nlocale.fr/mcp (streamable HTTP, no authentication)
- Tools: 10 read-only search and read tools
- Documentation: https://nlocale.fr/mcp/documentation.html
- Official MCP registry: io.github.nconcierge/nlocale
- Website: https://nlocale.fr
- Contact: bonjour@nlocale.fr

This repository only holds the listing metadata. The server is hosted; no code is published here.
